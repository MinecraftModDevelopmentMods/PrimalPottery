# Primal Pottery

Shape clay on a wheel.

The `main` branch is a Java mod built with Stonecutter. NeoForge covers 1.20.6, 1.21.1, and 26.3. Fabric covers 26.3. Shared sources are written for 26.3. The Forge 1.12 mod remains on the `1.12` branch.

`./gradlew collectJars` writes the loader jars to `build/libs/<version>/`.
